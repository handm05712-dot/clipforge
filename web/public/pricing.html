Questions, answered

Licence, models, costs and your footage.

Is it really free? +

Yes. The app is MIT-licensed and every feature is in the free download. Cutting, framing, captions and rendering use your own hardware, so there is no per-minute or per-credit charge.

Where does money ever come in? +

Only if you choose a cloud model for analysis or speech recognition. You enter your own API key and that provider bills you directly. Local models, and videos that already have captions, cost nothing.

Do I need an account or a card? +

No. Download the app, open it, and import a video. There is no sign-up wall before your first export.

Which video formats can I use? +

Anything FFmpeg reads — MP4, MOV, MKV, WEBM, M4V and AVI are the common ones. You can also paste a link to a public video, or import a subtitle file to skip transcription.

What hardware does it need? +

A recent laptop is enough for clipping and rendering. Running a local speech or language model wants more memory and benefits from a GPU — that is the one place a slower machine shows up.

Can I use my own fonts and caption style? +

Yes. The presets are data, not hard-coded looks: set the font, size, colours, stroke, shadow and animation, and save it as your own preset or as part of the brand kit.

Does it work offline? +

Clipping, rendering and local models work with no connection at all. You need internet only to download the app or a model the first time, and for cloud features you switch on yourself.

Who owns the clips I make? +

You do, subject to the rights you have in the source footage. There is no watermark and no licence claim on your exports. Make sure you have permission to reuse the original video.

Where are my files kept? +

In the app's own folder on your computer, and you can point it at another drive. Deleting a project removes its files. If you enable a cloud model, only the transcript (and audio, for cloud speech) is sent.

Can I use it for client work, or fork it? +

Yes. The MIT licence allows commercial use and modification. Keep the licence notice with any copy you redistribute, and rebrand it as your own if you want.
